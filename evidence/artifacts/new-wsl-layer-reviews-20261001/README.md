## Review contract

Each `<layer_id>.json` records the exact input revision, selected repositories and
pins of record, dated upstream currency, named alternative verdicts, native install
and acceptance commands, source corrections, failed access, omissions, remaining
gaps and reopening conditions. Source review, unchanged upstream tests, synthetic
fixtures, local integration and native provider execution retain their separate
evidence classes. Historical landscape winner pins are preserved as history; the
current stack/bootstrap and trading runtime target supply install pins of record.

`c4.independent_review_performed` records that review occurred.
`c4.no_unresolved_material_gap` is true only when the bounded review finds none.
A completed JSON file does not close its layer. The five closure criteria in
`catalogs/landscape/research-state.json` still govern selection and lifecycle
acceptance, with target-host checks collected later on the new distro.
