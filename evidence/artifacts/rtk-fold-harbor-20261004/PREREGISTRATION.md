## Metrics and adjudication

Primary: **wrong-path actions per trial**. The action unit is a tool call; a call containing several commands counts once when any access/edit names a nonexistent required file path or wrongly reconstructs a previously observed folded fragment. Repeated calls to the wrong path count again. Existing decoys count when a trajectory-supported mistaken prefix reconstruction causes the access/edit; ordinary exploratory reading of a valid unrelated file does not automatically count. Exclude URLs, grep patterns, option values and intentional existence checks from path-error labels; the task authorizes no new files. Record the exact call ID, command/tool arguments, resolved working directory, observation, offending path and rationale.

`measure.py` reads Harbor ATIF plus retained native rollouts, reconciles their tool-call ID sets, preserves both original argument forms, suggests candidates from literal paths, missing-path diagnostics and previously exposed folded tails, and emits an adjudication CSV. Candidates are **not** confirmatory labels. Missing native/ATIF coverage remains unknown and blocks scoring; recover/reconcile original source before analysis. A reviewer inspects every original trajectory call, including dynamic loops, Python scripts, free-form patches and calls the extractor cannot parse. Fill every CSV row with 0/1 and a reviewer; record offending paths and context in notes for positive labels. The review packet contains call evidence but omits arm labels, verifier rewards and arm manifests until labels are fixed; the output format can reveal exposure, so perfect blinding is impossible. `analyze.py` refuses missing labels or unreconciled coverage. Do not infer zero path errors merely from a passing verifier, or count a wrong edit from the verifier without linking its trajectory action. Retry counts are recomputed from adjudicated path errors; before adjudication the registered metric remains null.

Secondary: exact task pass rate (Harbor reward), identical-command retries after a path failure (computed from trajectory; other correction attempts may be described with call IDs), and Harbor's input/output/cache token counts, with nulls preserved when unavailable. Report every actual grep spelling and exposure; built-in search, pipelines, redirects, explicit RTK, zero/one-match searches and hook skips can prevent or alter the fold.

Exposure evidence is separate from outcome: `RTK_HOOK_AUDIT=1` records hook decisions in RTK's own audit log. A must have a grep rewrite record **and** the matching folded tool observation. B normally has an invoked hook with a skip/no-rewrite record, then an unfolded observation. C has no RTK registration or audit and an unfolded observation. D must separately demonstrate its handler. B's `hook_fired=true` is correct when the functioning hook declines rewriting; it does not mean B folded. These audit files and exact command exit codes are collected without replacing the hook. [Upstream audit implementation](https://github.com/rtk-ai/rtk/blob/e001f773f80b22b7dc4c7a79521b30e35aaef026/src/hooks/hook_cmd.rs).
