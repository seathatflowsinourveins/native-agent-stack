**VERDICT: conflict** — [SKILL.md](m4/SKILL.md:20) L20, L28 and L42 conflict with [AGENTS.md](m4/AGENTS.md:16) L16.

**Freshness: real conflict.** SKILL L20 says “If you haven't run the verification command in this message, you cannot claim it passes”; L28 requires “Execute the FULL command (fresh, complete)”; L42 explicitly lists “Previous run” as insufficient for “Tests pass.” AGENTS L16 instead requires “Reuse passing evidence when its inputs still match and run only checks needed for a concrete gap.” Realistic case: a suite passed earlier, all relevant inputs are already established unchanged, and a later status reply needs to report that result. Repeating the tests solely to satisfy the message boundary violates AGENTS; reporting the applicable passing result without rerunning violates SKILL. “FULL command” alone need not mean the entire suite—the mandatory freshness is the conflict. **Broad triggers: compatible with the bounded-work clause.** SKILL L108–114 says “ALWAYS before” “ANY positive statement about work state,” “Moving to next task,” and “Delegating to agents.” AGENTS L15 says “do not add intake, brainstorming or separate planning approval to bounded work” and “Stop only for necessary native sign-in, operating system consent or an unresolved material decision.” These triggers can require autonomous evidence checks during authorized work without introducing intake, approval or a user-facing halt; unnecessary reruns remain the first conflict. **Other full-read provisions:** SKILL L96’s “Create checklist → Verify each” fits AGENTS L15’s “short internal plan”; SKILL L69’s “Verify independently” fits AGENTS L13’s “actual returned output and independent observation.” Neither establishes another conflict.

**Disposition: remove now.** [The trial rule, L15–17](m4/skills-trial-excerpt.md:15) requires immediate removal upon a conflict found through a full read. Measurable harm is an alternative trigger, not an additional requirement. Keeping it with a recorded reading would require overriding its explicit freshness requirement.
