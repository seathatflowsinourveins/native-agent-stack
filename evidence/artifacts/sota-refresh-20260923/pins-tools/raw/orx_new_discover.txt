Call one paper-retrieval primitive; the caller owns the search loop

Usage: orx discover [OPTIONS] <COMMAND>

Commands:
  keyword    alphaXiv full-text BM25 retrieval with match snippets
  embedding  alphaXiv semantic title/abstract retrieval with similarity/popularity reranking
  openalex   OpenAlex scholarly-graph search across disciplines
  biorxiv    bioRxiv preprint search through OpenAlex's bioRxiv source index

Options:
      --no-telemetry  Disable anonymous usage analytics for this run. To disable it persistently, run `orx telemetry off`
  -h, --help          Print help
