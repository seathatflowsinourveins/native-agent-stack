agentsview v0.43.0 - local web viewer for AI agent sessions

Syncs session data from supported AI coding agents into SQLite,
serves analytics, and exposes a session browser via local web UI.

Usage:
  agentsview [flags]
  agentsview <command> [flags]

Core Commands:
  daemon                 Manage the background server
  daemon restart         Restart the background server
  daemon start           Start the background server
  daemon status          Show background server status
  daemon stop            Stop the background server
  health                 Show session health and signals
  projects               List projects with session counts
  prune                  Delete sessions matching filters
  serve                  Start the web UI and sync server
  serve restart          Restart the writable SQLite background daemon
  serve status           Show whether a server is running and where to reach it
  serve stop             Stop the server, including sync and file watchers
  sync                   Refresh session data and exit

Watcher excludes:
  Add "watch_exclude_patterns" to ~/.agentsview/config.toml
  to skip directory names/patterns while recursively watching roots.
  Example:
  watch_exclude_patterns = [".git", "node_modules", ".next", "dist"]

Session cwd filter:
  Add "sync_include_cwd_prefixes" to ~/.agentsview/config.toml to
  ingest only sessions whose working directory is under one of the
  listed paths. Sessions without a recorded cwd are skipped while
  the filter is set. Applies to local sync only. Example:
  sync_include_cwd_prefixes = ["/home/example/work"]

Multiple directories:
  Add arrays to ~/.agentsview/config.toml to scan multiple locations:
  [agents.claude]
  dirs = ["/path/one", "/path/two"]
  [agents.codex]
  dirs = ["/codex/a", "/codex/b"]
  When set, these override default directories. Environment variables
  override config file arrays.

Remote hosts:
  Add a [[remote_hosts]] array to ~/.agentsview/config.toml so that
  "agentsview sync" (no --host) also syncs each configured host:
  [[remote_hosts]]
  host = "devbox1"
  transport = "ssh" # optional; default
  user = "jesse"  # optional
  port = 22        # optional
  Requires key-based (passwordless) SSH to each host.

  For daemon-backed HTTP sync over a private network such as Tailscale:
  [[remote_hosts]]
  host = "devbox1"
  transport = "http"
  url = "http://devbox1.tailnet.ts.net:8080"
  token = "remote-token" # required; remote daemon auth_token
  Each host must be unique.

  Top-level daemon_idle_timeout = "0s" keeps serve --background nodes alive.

Data stored in ~/.agentsview/ by default.
