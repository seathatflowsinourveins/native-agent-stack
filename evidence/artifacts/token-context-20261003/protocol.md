## Gates, schedule and counted-once metrics

Qualification gates precede comparative model trials: source/bundle identity, unchanged upstream tests, exact roundtrip/exit/fact controls, eligible task exposure and native usage calibration. Preserve every failure and unknown. A failed prerequisite excludes that candidate scope; it does not prove another unmeasured property.

Run two A/A blocks per client/job as calibration, never part of confirmatory savings. Then12 matched A/B blocks per eligible model task/client: odd blocks AB, even blocks BA, one native case at a time. Provider order is explicit per upstream configuration; no adaptive arm ordering. Freeze exact task prompts/oracles/configuration and hashes before confirmatory execution. No replacement of failed attempts; report all attempts and accepted-task denominator. A declared failure may have one bounded diagnostic recovery whose extra usage remains charged to that attempt.

Quality requires every critical fact/type/exit/constraint and source locator correct; zero false-success outcomes; recovery reproduces every required original. Candidate must have no paired critical-quality loss. Narrative quality, if needed, is independently read blind to arm with a predeclared rubric; unresolved disagreement prevents promotion. These fixed cases qualify only their declared workload, never broad SOTA superiority.

Efficiency gate: on accepted matched cases, candidate/native whole-trajectory exact token ratio must be at most0.90 and its paired95% interval exclude1.00 using a maintained upstream statistical implementation, named before freeze. Keep cache-category differences and uncached input visible. If the interval is inconclusive, retain native practice under the no-install rule and report “native baseline wins by the no-install rule; superiority unproved”, not an observed causal native advantage. Protection has a separate gate: observed natural compaction/resume,100% retained constraints, and an observed decrease in peak active-context/request input or fewer required compactions at equivalent quality. Estimated occupancy is labelled; no short-output-only protection claim.

Artifacts use existing `tools/token-report/token_manifest.py compare`, explicit `gpt-tokenizer4.0.0` / `o200k_base`. Count payload, instructions, schemas, tool requests/results, primers, retries and recovery once at their boundaries. Those artifact totals are separate from provider trajectories. Codex exact `payload.usage` is deduplicated by response ID; turn/thread snapshots only reconcile. Claude per-message executor iterations are disjoint request counters; cache creation/read are distinct categories, thinking is inside output. Advisor-message iterations are separately billed; child/root aggregates cannot be added again. Unknown raw usage, stopped advisor results, retries or cost remain unknown; incomplete coverage cannot pass a saving gate.
