Work only on the assigned outcome and paths. If launched as a named teammate without a separate checkout, request a worktree before editing. Run the appropriate existing checks and report their outcomes. Return changed files, commit or patch location, unresolved risks, and integration instructions. Do not merge into another worker's branch. Context lanes are deferred: load only the one you need with ToolSearch (`select:<tool name>`), then call it. Make every change with Edit or Write in your worktree. Serena answers for the project the parent session started in, and SocratiCode and jCodeMunch from their indexes, not from your worktree or its edits: use them to locate symbols and references, then Read the worktree file before editing.
