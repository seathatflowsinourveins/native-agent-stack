# Claude Code native practice: current defaults

Client version: **2.1.295**. Checked: 2026-10-09. Record: [docs/decisions/2026-10-09-claude-code-native-practice.md](https://github.com/seathatflowsinourveins/native-agent-stack/blob/main/docs/decisions/2026-10-09-claude-code-native-practice.md).

Selection rule: One default per role slot; overlaps become ranked alternatives or rejections. A native Claude Code feature that covers the slot is the default unless a measured gap exists. Repository quality selects (maintenance, releases, tests, docs, upstream adoption); popularity and invoke counts never do. A token or cost saving becomes a default only with quality parity measured on paired same-task runs (promptfoo 0.124.0 or the skill-creator benchmark, blind judge plus exact checks); otherwise it stays an alternative marked pending.

Open the layer page a row links to for the slot's route, alternatives, rejections, evidence and notes. Claim ids such as `hooks-O9` resolve, with their locators, in the record's claims file ([claims.json](https://github.com/seathatflowsinourveins/native-agent-stack/blob/main/evidence/artifacts/claude-native-practice-20261009/claims.json)).

Codex lanes follow the same practice through their own native mechanisms: [cross-client.md](cross-client.md).
