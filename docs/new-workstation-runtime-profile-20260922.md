# New workstation runtime profile (2026-09-22)

Projection for the planned WSL2 workstation (AMD Threadripper PRO 5975WX, 32 cores / 64 threads, RTX 4090 24 GB, 128 GB RAM) that will carry only Codex, Claude Code and the runtime worker-hosting services. Nothing in this record was measured on that machine; every number is either copied from a dated record made on the current laptop (Core Ultra 9 275HX, 24 threads, 31 GB, RTX 5090 Laptop 24 GB, observed with `nproc`, `free -g` and `nvidia-smi` on 2026-09-22) or a stated proposal marked untested. Source run: `wf_451ec95d-224` (four research sweeps, Opus synthesis, two Opus verifiers; 7 agents, 755,303 child tokens, 28 min). The verifiers refuted six synthesized statuses and found the install gaps listed below; both are applied here, so this record supersedes the raw synthesis.

With 48 processors the default concurrency cap is still min(16, 46) = 16.

## Codex configuration rules (verified against `.codex/config.toml` and the config reference)

`[agents] enabled = true`, `max_concurrent_threads_per_session = 3`, mirrored in the catalog example when it changes. `[shell_environment_policy.set]` lists the ecosystem bin first with fully resolved absolute paths (TOML does not expand `$PATH`) and sets `RTK_TELEMETRY_DISABLED = "1"`. MCP servers are registered explicitly under `[mcp_servers.<id>]` with `startup_timeout_sec`, and the plugin-scoped duplicate stays disabled so a server is not started twice; grant named tools with `enabled_tools`/`disabled_tools` rather than whole servers (adopted for the workstation; this project's own `.codex/config.toml` registers its five servers without those filters, so enforcement is not demonstrated here, as the Codex Lane C review noted). Role layers go under `[agents."<name>"]` with `description` and `config_file`, or simply as `.toml` files under `.codex/agents/`, which the loader discovers recursively (source at `rust-v0.155.1`: `codex-rs/agent-roles/src/discovery.rs`, `loader.rs`); a role file's own `description` overrides the table entry's. The Stop-time review gate stays off and the `codex-rescue` subagent denied; cross-family review runs through Lane C or the foreground `/codex:review` path from a dedicated checkout, because the companion broker is workspace-keyed. Codex keeps explicit `rtk` on PATH; the prerelease automatic rewrite hook stays inactive.
