At `18eea2c1de992b46c266d79ef0cc40f93c9fb943`, the catalog-freshness workflow creates and updates a report-only PR without a lane label or a SOTA-sources section. Native GitHub reads confirmed both omissions on [PR527](https://github.com/seathatflowsinourveins/native-agent-stack/pull/527). The required `sota-sources` check needs a nonempty, case-sensitive section, and `docs/lanes.md` requires a lane label.

The workflow now supplies a lane label and matching description plus `### SOTA sources`. New or unlabeled reports default to `lane:shared`: their source observations cover both foundation and trading catalogs (`scripts/freshness_propose.py`), and `docs/lanes.md` assigns changes serving both lanes to shared. Updates preserve a single existing supported lane label; ambiguous or unknown lane labels stop the metadata step for owner resolution. A create-race fallback re-reads the winning PR's label before editing its description. This foundation automation repair does not itself change a trading selection or shared policy; generated shared reports retain their existing cross-lane acknowledgement requirement.

The description remains independent of any particular workflow run. Its source section links the current PR's source-review artifacts and GitHub CLI interfaces reviewed at a pinned revision; the actual hosted executable comes from the runner image. Existing PRs whose old bodies lacked source metadata can need one human-authenticated body edit after approval, because the branch push precedes the bot description edit. A failed run retains its original event payload, and `GITHUB_TOKEN` body edits do not start a new run. This migration step is explained in the workflow summary and [automation guide](../github-automation.md); no additional token or dispatch mechanism is introduced.

The existing workflow permission scope, opt-in conditions, branch lease, report-only semantics, approval-required behavior and manual review remain unchanged. No job is dispatched by this change, and no upstream candidate or runtime pin is selected.
