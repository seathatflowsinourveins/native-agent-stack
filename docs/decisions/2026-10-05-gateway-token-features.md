## Decision and overturn condition

Retain the existing shared gateway settings and owner boundaries. Defer global engine/outputstyle or SDK middleware activation until an owner-isolated route demonstrates semantic quality, correct protocol handling, original recovery and complete non-overlapping usage on frozen matched tasks. The current preview already returned RTK fallbacks (including URL-validation failure) and Caveman no-op artifacts; neither justifies global activation.

Reject a custom evaluation runner, a rebuilt upstream harness and copying native client hooks into unrelated SDKs. Keep native caching, accounts, compaction and deferred discovery intact. Do not transfer historical or source-only acceptance into current worker claims. The next decision-changing comparison is owner-run integrated input/tool/outputstyle A/B, preserving endpoint/role/content modalities and reporting actual provider usage plus retries, preparation and recovery. A smaller artifact reduction alone cannot overturn this decision.
