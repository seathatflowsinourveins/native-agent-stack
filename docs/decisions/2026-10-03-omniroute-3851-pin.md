`c1e30b7676975feb298b49eff6ff58923c04b89e`. The

waiting period can end sooner as needed with clean upstream releases".
That statement ends the cooldown hold for this qualified clean release.

The alternatives are retaining the prior qualified pin at
`5458026c216f77a3da68ea49152dc33470cfe2cb`, selecting the mutable development
branch, or representing a deployed patched build as the upstream release.
The release is selected because it has its own retained npm qualification
and source-backed GPT-6 effort fix. The current development branch is
`release/v3.8.52`; it is not the latest stable release. Deployment carries
have separate provenance and cannot identify the clean npm package.

Overturn this decision if a clean upstream release supersedes it and has
matching package/source identity and scoped native installation/boot
qualification, or if a reproducible compatibility regression invalidates
the retained qualification. Compare the named release's own supported

`evidence/receipts/omniroute-3851-npm-qualification-20260930.json`; use an
upstream harness for any new gateway/model comparison. This pin change
