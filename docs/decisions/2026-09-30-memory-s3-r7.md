## Decision

The preregistration becomes DRAFT r7 ([`blueprints/memory-layer-s3/PREREGISTRATION.md`](../../blueprints/memory-layer-s3/PREREGISTRATION.md)):
1. **Maintenance gate (section 1).**
   - A repository is stale if it is archived, or if it has no default-branch commit in 90 days. This is the floor of OpenSSF Scorecard's Maintained check (v5.5.0 `checks/evaluation/maintained.go:31-32,88-100`).
   - The gate runs through `gh api` at freeze and before every run.
   - **ACCEPTED user decision 3:** every repository selected to run (harness, memory/RAG system or tool) must pass Maintained. Transitive dependencies require a per-arm SBOM and a clean osv-scanner result; stale transitive dependencies are flagged without blocking their harness. LongMemEval `9e0b455f` appears only as a citation, and its dataset file is static data pinned by sha256.
2. **Candidates at current releases, with tag and full commit (section 3).**
   - Primary candidates: agentmemory v0.9.29, Hindsight v0.10.2, OpenViking v0.4.22, cognee v1.6.2, MemPalace v3.10.0, basic-memory v0.23.2 and memsearch v0.4.21.
   - ai-memory v2.4.2 competes without protected status.
   - Reserves: engram, Graphiti and supermemory-local.
    - Mem0, Letta and beads are out on fit, each with its locator.
    - These historical sets are superseded by "Pre-freeze candidate additions (2026-09-30)" below.
3. **Harness (section 4).**
   - AMB runs byte-identical at `03c1d0f1`.
   - The LongMemEval adapters, the recall scorer (implemented from the paper's metric definition) and the thin provider clients live in this repository. Since the repair round every system has one, Hindsight included, and no AMB provider is reused.
   - AMB's locked mem0 1.0.5, cognee 0.5.4 and hindsight-all 0.4.17 implement no candidate arm, but provider-module imports execute. The accepted dependency scope replaces round 2's executing-closure maintenance rule: include imports in every arm's SBOM/OSV scan; unknown vulnerability acceptance keeps AMB pending. Flag `rank_bm25` 0.2.2 (supplied source's last commit 2024-10-08), without making its age a harness blocker.
   - Answerer and judge are OpenAI-compatible `cx/gpt-6-astra-max` through the local gateway.
   - Vendor-bias controls: a judge-free primary metric, equal recall-depth policy, one parity checklist for every system, a GPT-6 adversarial audit, and no use of the vendor leaderboard. Open QA receives the shortest final-ranking prefix covering five distinct sessions, capped at 20 items, with emitted context tokens recorded per arm.
4. **Symmetric merit rule (sections 6–7), replacing the reference and the replacement routes.**
   - All-pairs paired cluster-bootstrap tests use r6's seed, 20260927, with Holm adjustment through `statsmodels` `multipletests` over the frozen m = k(k−1)/2 pairs.
   - The leader on `recall_all@5` wins. Several systems sharing the maximum are all leaders. A system inside the 0.02 practical-equivalence band joins them in tie-break 1 only if Holm finds it significantly worse than no leader (repair round 1). Tie-break 1 is gross cost at frozen list prices; tie-break 2 is a Scorecard-based repo-quality score with an exact formula.
5. **Token ledger (5.2):**
   - OmniRoute ingest usage per system and role;
   - o200k recall payloads counted with gpt-tokenizer 4.0.0;
   - native per-session usage from `claude -p --output-format json` and `codex exec --json`, run in scratch `CLAUDE_CONFIG_DIR` and `CODEX_HOME` homes;
   - latency p95 and resources.
6. **RAG section (8).**
    - A document-RAG head-to-head: qmd, LightRAG, a llama_index hybrid pipeline, OpenViking, memsearch and cognee search, each wrapped as an MTEB 2.21.10 `SearchProtocol` model.
    - This historical set is superseded by "Pre-freeze candidate additions (2026-09-30)" below.
   - Embedder and reranker selection on LoCoMo (memory), CoIR (code) and a disjoint half of the `MTEB(eng, v2)` retrieval tasks (documents). Incumbents compete as equals.
   - S8 regenerates SWE-bench Verified tasks through Harbor's maintained adapter and stays pending until its own dated amendment. Under the user's round-2 decision it is a short-code do-no-harm check, not the main usefulness test or a coupling that blocks host selection.
7. **Long-workflow usefulness and fallback (ACCEPTED 2026-09-30).**
   - LongMemEval-V2 `2cc8c540` is the main test: the same direct native harness argv per domain for all arms/control, five paired replications, superiority to no retrieval and no significant loss to any **eligible, completely observed** best memory system, with a separately frozen Holm family. Outcome-independent shared-trajectory haystack components are the resampling unit; preflight must verify at least 20 against downloaded files, or usefulness stays pending. A baseline final-failure rate above 5% makes the entire family pending. MemoryAgentBench `538026089` is secondary only for applicable native modes (currently agentmemory normalized-fact CR, pending acceptance); a vendored copy cannot represent a selected candidate. MemoryArena `6cd9de14` is stale and citation-only. This replaces the minus-one floor and S8 usefulness coupling.
   - When complete valid evidence establishes that no system qualifies, deploy the operationally eligible system with the best primary score. Eligibility requires the selected-repository gate, dependency SBOM/OSV acceptance, demonstrated native deployment/lifecycle, gateway/network/latency/observer acceptance and no failed hard gate. There is no incumbent default. Fallback is labelled usefulness-unqualified; an empty set, insufficient usefulness clusters or a pending contender able to change qualification/selection remains unresolved.
8. **Status:** DRAFT r7; the complete freeze needs the user's acceptance and a GPT-6 cross-family review.
