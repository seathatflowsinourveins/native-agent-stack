**Status:** draft. It takes effect only with the S3 freeze, which needs both the user's acceptance and a GPT-6 cross-family review of the complete bundle ([preregistration, section 11](../../blueprints/memory-layer-s3/PREREGISTRATION.md#11-freeze-procedure)).

## Context

r6 (DRAFT, 2026-09-27) compared seven primary memory systems against a frozen ai-memory v2.4.0 reference arm (C3′/C4′):
- a candidate replaced the reference only through a superiority route or a non-inferiority-plus-cost route;
- the Holm family held 14 hypotheses;
- LongMemEval's own scorer and judge prompt were to run unchanged.

On 2026-09-30 the user restated the memory-layer requirements below, and the coordinator's brief asked for r7 with eight named changes.

## Why: the user's words

As relayed by the brief, which quotes the user's messages of 2026-09-30; this record did not hear them directly:

## Decision

The preregistration becomes DRAFT r7 ([`blueprints/memory-layer-s3/PREREGISTRATION.md`](../../blueprints/memory-layer-s3/PREREGISTRATION.md)):
1. **Maintenance gate (section 1).**
   - A repository is stale if it is archived, or if it has no default-branch commit in 90 days. This is the floor of OpenSSF Scorecard's Maintained check (v5.5.0 `checks/evaluation/maintained.go:31-32,88-100`).
   - The gate runs through `gh api` at freeze and before every run.
   - No code from a stale repository executes. LongMemEval `9e0b455f` appears only as a citation, and its dataset file is static data pinned by sha256.
2. **Candidates at current releases, with tag and full commit (section 3).**
   - Primary candidates: agentmemory v0.9.29, Hindsight v0.10.2, OpenViking v0.4.22, cognee v1.6.2, MemPalace v3.10.0, basic-memory v0.23.2 and memsearch v0.4.21.
   - ai-memory v2.4.2 competes without protected status.
   - Reserves: engram, Graphiti and supermemory-local.
   - Mem0, Letta and beads are out on fit, each with its locator.
3. **Harness (section 4).**
   - AMB runs byte-identical at `03c1d0f1`.
   - The LongMemEval adapters, the recall scorer (implemented from the paper's metric definition) and the thin provider clients live in this repository.
   - AMB's locked mem0 1.0.5, cognee 0.5.4 and hindsight-all 0.4.17 serve no arm.
   - Answerer and judge are OpenAI-compatible `cx/gpt-6-astra-max` through the local gateway.
   - Vendor-bias controls: a judge-free primary metric, equal k, one parity checklist for every system, a GPT-6 adversarial audit, and no use of the vendor leaderboard.
4. **Symmetric merit rule (sections 6–7), replacing the reference and the replacement routes.**
   - All-pairs paired cluster-bootstrap tests use r6's seed, 20260927, with Holm adjustment through `statsmodels` `multipletests` over the frozen m = k(k−1)/2 pairs.
   - The leader on `recall_all@5` wins. Systems inside a 0.02 practical-equivalence band that Holm does not separate from the leader go to tie-break 1, cost at frozen list prices, then tie-break 2, a Scorecard-based repo-quality score with an exact formula.
5. **Token ledger (5.2):**
   - OmniRoute ingest usage per system and role;
   - o200k recall payloads counted with gpt-tokenizer 4.0.0;
   - native per-session usage from `claude -p --output-format json` and `codex exec --json`, run in scratch `CLAUDE_CONFIG_DIR` and `CODEX_HOME` homes;
   - latency p95 and resources.
6. **RAG section (8).**
   - A document-RAG head-to-head: qmd, LightRAG, a llama_index hybrid pipeline, OpenViking, memsearch and cognee search, each wrapped as an MTEB 2.21.10 `SearchProtocol` model.
   - Embedder and reranker selection on LoCoMo (memory), CoIR (code) and a disjoint half of the `MTEB(eng, v2)` retrieval tasks (documents). Incumbents compete as equals.
   - Code retrieval's whole-task value comes from the separate Harbor lane.
7. **Status:** DRAFT r7; the freeze needs the user's acceptance and a GPT-6 cross-family review.

## Brief items adjusted on primary evidence

- (a) "rag mode only" is kept for the answer-generating open-QA variant. The retrieval variant has to run AMB's `retrieval` mode (evidence above).
- (b) AMB's `supermemory` provider is not reused for supermemory-local; a thin client in this repository replaces it.
- (c) Mem0's plugin URL is a default with an override, not a hard-coded value. The exclusion stands on the Platform routes it calls.
- (d) Free VRAM on the RTX 4090 measured 12,726 MiB, then 12,005 MiB at 03:13:24Z, not about 13.7 GB. Nemotron-3-Embed-8B-BF16 does not fit and is `pending`.
- (e) CoIR's repository is stale too, so CoIR enters only as MTEB task data.
- (f) AMB's per-category LongMemEval judge prompts have no abstention branch. The 30 abstention questions form their own reported stratum, and the gap is a recorded validity limit.

## Coordinator decisions awaiting the user's acceptance

The brief does not settle these, so they are made here and listed for acceptance at the freeze:
- the optional-stage rule, which selects an optional recall stage such as ai-memory's opt-in LLM reranker per system on the development split;
- the fallback preflight, generalized to every system with a silent-fallback LLM stage;
- agentmemory's embedder follows the same development selection as every configurable system, and r6's coordinator-directed MiniLM exception (B:C) becomes a diagnostic unless reaffirmed;
- the usefulness floor becomes "at least the best eligible system's successes minus one";
- the cost scalar uses a list-price table frozen at freeze, with r6's 0.80× cost ratio;
- the repo-quality score adds a release-cadence term and a CI-on-pinned-commit term, each at Scorecard's Low weight;
- the `MTEB(eng, v2)` retrieval tasks are split by corpus size: the five smallest evaluate RAG systems and the five largest select document embedders;
- the RAG feasibility window defaults to 96 h per host.

## Alternatives considered

- **Keep r6's reference design, with ai-memory v2.4.2 as the reference.** Rejected: it gives the incumbent protected status, contrary to the user's third requirement.
- **A leader-versus-rest family (m = k − 1).** Rejected: the leader is chosen from the same data, so the family is not fixed before results. The all-pairs family is fixed in advance and treats every system alike.
- **Hsu's multiple comparisons with the best.** Not adopted: the brief specifies Holm-adjusted paired tests through `statsmodels` `multipletests`, and a second, unpinned procedure would widen the review surface.
- **r6's +0.05 superiority margin as the winning condition.** Rejected: the brief makes the best point estimate the winner, with a 0.02 practical-equivalence band.
- **Running LongMemEval's `eval_utils.py` unchanged, as r6 planned.** Rejected: the repository is stale, and the code cannot run under NumPy 2.
- **LongMemEval's `get_anscheck_prompt` for open QA.** Not used: the brief directs AMB's per-category prompts. The abstention gap is recorded instead.
- **Stars, downloads or awesome-list presence as quality.** Rejected by the user's rule. Scorecard checks, release cadence and CI on the pinned commit are used instead, and only to break ties.
- **Selecting document embedders on the same MTEB tasks that evaluate RAG systems.** Rejected as leakage. The tasks are partitioned before any result.

## Overturn conditions

- The user rejects any coordinator decision listed above: revise before freeze, never after a confirmatory result.
- The GPT-6 cross-family review finds that the all-pairs family or the tie-break set misstates the estimand or fails error control: revise before freeze.
- The maintenance gate, at freeze or before any run, finds an executing repository stale: that code stops, and a dated amendment follows.
- Any pinned system publishes a newer release before freeze: re-pin by dated revision before freeze.
- The wire check shows AMB's answerer or judge calls served from cache or replayed: add a frozen header-carrying integration by amendment before scoring.
- The Harbor lane's receipt contradicts the relayed codebase-memory `/testbed` refusal: correct 8.4.
- A GPU window approved by the user, or an official quantized artifact: Nemotron-3-Embed-8B moves from `pending` into the selection run.

## Limitations

- No deployment, provider call or scored run was made. The live checks are metadata and source reads.
- The user's words are relayed by the brief.
- The ai-memory v2.4.2 re-pin is not yet in `manifests/stack.json`, which still lists 2.4.1.
- `blueprints/memory-stack/longmemeval/A17-SUPERSESSION.md` (lines 16 and 19–21) still describes the r4–r6 reference arm. It lies outside this change's paths and must be revised before the freeze.
- The gateway's strict `json_schema` support and the codebase-memory `/testbed` refusal are relayed facts, pending their own receipts.
- Illustrative power to separate differences of 0.02 is at most 0.28, so the rule decides on point estimates and uses the tests to label results and to bar significantly worse systems from the tie-break.
