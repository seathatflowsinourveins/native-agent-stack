# PR561 token lifecycle port and retirement

Date: 2026-10-03. Lane: foundation.

Decision: port the four still-useful integrations from PR561 head
`fe4729d98b16fb71445373b6da4ea07da8b4b8cf` onto base
`cac8700ba914950266272347468bff7ad630a4bf`, and retire the remaining changes
with immutable source links. The historical scope is the old NativeStack distro
on the source workstation, 2026-09-30 through 2026-10-01. It establishes no
NativeStack2604 or Mac acceptance. This port serves the foundation needed for
US-equities research and historical simulation at the selected destination.

## Primary sources and alternatives

The reproduction pin is ai-memory 2.4.2 at
[`a0ca8d1`, install_hooks.rs L1513–1565](https://github.com/akitaonrails/ai-memory/blob/a0ca8d1a5fbd5920799411fa891fe6d49c90efc1/crates/ai-memory-cli/src/commands/install_hooks.rs#L1513).
The selected v2.5.2 source at `7580b74d0fb9d14a6d949dc92f5ea8bb7feb3c83`
still classifies an outer entry by any owned inner command and filters the whole
entry during overlay:
[`is_ai_memory_hook_entry`, L1583](https://github.com/akitaonrails/ai-memory/blob/7580b74d0fb9d14a6d949dc92f5ea8bb7feb3c83/crates/ai-memory-cli/src/commands/install_hooks.rs#L1583),
[`overlay_event_hooks`, L1619](https://github.com/akitaonrails/ai-memory/blob/7580b74d0fb9d14a6d949dc92f5ea8bb7feb3c83/crates/ai-memory-cli/src/commands/install_hooks.rs#L1619).
[`uninstall.rs` L825](https://github.com/akitaonrails/ai-memory/blob/7580b74d0fb9d14a6d949dc92f5ea8bb7feb3c83/crates/ai-memory-cli/src/commands/uninstall.rs#L825)
defines the native/legacy command signatures; it is not a claim that uninstall
uses the same whole-entry removal behavior. These originals were reread for this
port. The v2.5.2 tag object is `af8c6820`, resolving to `7580b74d`.

Serena's immutable `c6fbd1c5932df2494ffa0020af5a9fbe80b82143` originals explain
[ancestor activation](https://github.com/oraios/serena/blob/c6fbd1c5932df2494ffa0020af5a9fbe80b82143/src/serena/cli.py#L369-L383),
[the single-project predicate](https://github.com/oraios/serena/blob/c6fbd1c5932df2494ffa0020af5a9fbe80b82143/src/serena/agent.py#L699-L701)
and [the two-tool exclusion](https://github.com/oraios/serena/blob/c6fbd1c5932df2494ffa0020af5a9fbe80b82143/src/serena/agent.py#L839-L848).
Workflow installation follows Claude's
[personal saved-workflow layout and target-symlink rules](https://code.claude.com/docs/en/workflows#save-the-workflow-for-reuse)
and current main's [reviewed SHA256SUMS](../../examples/claude-native/workflows/SHA256SUMS).

Keeping the stale PR wholesale would move superseded pins and historical
qualification into living documents. Dropping it wholesale would lose three
useful integrations and the exact Serena preimages. Porting workflows into the
default step list would change bootstrap behavior. The selected bounded port
avoids those effects while retaining the unique historical facts below.
