The restricted assignment format is the intersection of environment.d, POSIX shell and [stdlib TOML](https://docs.python.org/3.13/library/tomllib.html): quoted string assignments, the literal telemetry integer, and braced references to known earlier variables. Reuse existing `string.Template` rendering rather than create a general dotenv parser. Reject undefined references, executable substitutions, extra keys and control characters.

F9 resolves the source for the selected conventional HOME and renders the same values into the environment.d file and the explicit Codex `set` table. `inherit = "none"` stays. The new `login-env` step uses the existing atomic writer and managed `profile-env` block; it preserves operator text and allexport state. Initial file bytes or absence authorize the write; a concurrent edit produces a failed-step result and is retained. Existing files receive the standard backup. No credential store is opened or copied.

`--check-login-env --host NAME` reads back only configuration metadata: source bytes, the managed profile reader, conventional Bash shadow files, base Codex values and filter compatibility. It conservatively rejects custom `include_only`/`filters` policies rather than reproducing the native matcher. It does not establish active-profile or actual new-session acceptance. `credential_status.py --require-pointers` separately compares all eight environment pointers with canonical inventory paths, reporting names and booleans only. Missing owner inventory declarations fail explicitly. It does not resolve or inspect targets; optional credential-file presence stays informational.

The value-free native checker observed `grafana-admin` as `ok`, file mode 0600 and directory mode 0700. This is location/presence evidence, not producer or service acceptance. Host generation-key regeneration remains conditional on moving its service; the firewall-lane store remains conditional on Phase 3 selecting an actual 20129 route. Neither condition runs here.

From 2026-10-07, paper-unit generation uses direct runner `--env-file` arguments and no `bash -ic`; the 2026-10-06 units and historical receipts stay untouched.
