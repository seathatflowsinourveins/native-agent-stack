# Native runtime roles and capability setup

Use this resolution when a foundation task needs a native CLI, SDK harness,
persisted research worker or evaluator. The [dated source packet](../catalogs/foundation/native-runtime-role-resolution-20260930.json)
records the release pins, discovery coverage, decisions and corrections. Read
only the selected role's recipe and evidence before dispatch.

Retain native Codex/Claude coordination and the qualified Codex SDK/Dagu coding
lane. Add separate capability trials for OpenHands CLI/SDK and DeepAgents'
persisted research role. Optional frameworks remain task-specific alternatives.
Current source coverage includes public stars and four maintained awesome lists;
those inputs discover candidates, while native results determine adoption.

Give each selected worker an explicit role, source-pinned native model/effort,
owned workspace and private state, selected skill/tools, deadline and returned
result contract. Use Sol-Max for the main worker; invoke Astra-Max when the
task needs consequential judgment. Load skill bodies and MCP tools when the
task needs them, retaining native cache and compaction behavior. Report each
failed attempt and native usage scope; measured savings require a comparison.
