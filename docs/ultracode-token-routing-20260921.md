## Limits

First-prompt figures come from one tiny task on one host and model; they bound the fixed spawn cost, not the cost of a real task, and are not a savings rate. The Haiku judgment rests on one packet and one Opus verifier. Both inventories ran while the coordinator was editing the same files, so some of their rows describe an intermediate state (the verifier marked those "corrected"). Agent definitions created or edited mid-session became available only at the next turn boundary. The documented packet description is bound to the code only at the level of lane names. `structure()` in `test-envelope.mjs` does not handle a `/` inside a regex character class, and blanks template-literal contents (an `agent(` there fails closed). Provider figures reach the repository only as `child-usage.mjs` output; the raw transcripts stay in the native session store.
