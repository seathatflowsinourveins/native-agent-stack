# Claude Code native practice

The current default for each Claude Code role slot lives with the
[`claude-native-practice` skill](../.claude/skills/claude-native-practice/SKILL.md), so it travels wherever the skill is
installed:

- [index of the 33 role slots](../.claude/skills/claude-native-practice/reference/slots.md), each with its status,
  default and overturn condition, and one page per layer behind it;
- [the same content as JSON](../.claude/skills/claude-native-practice/reference/slots.json).

The dated evidence behind the defaults (capability matrix, supersession table, measurements owed and the refresh loop)
is [the 2026-10-09 decision record](decisions/2026-10-09-claude-code-native-practice.md). Sessions reach the page
through the skill; nothing here is always loaded.
