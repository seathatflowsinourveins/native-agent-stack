## What was actually reviewed

Claude used ten broad groups covering the 20 catalog layers. Its discovery
produced **514 group entries, 426 distinct repository URLs**, not 514 unique
repositories. Refuters named 41 distinct alternatives, 15 additional identities;
the combined discovery set is **441**. Joining this with the prior 540-identity
catalog adds **303** research-only identities, giving **843**. Current public
stars remain a separate 343-repository snapshot; counts do not measure quality.

The native run reports 63 completed children. Explicit-directory usage analysis
finds **65 started attempts, 63 completed, and two earlier judge attempts without
terminal journal results**. Workflow-level zero errors describes eventual workflow
completion, not an absence of retries or incomplete attempts. The handed-over
`child-usage-latest.txt` had already selected the subsequently running coverage
workflow. The [published WF2 usage](../evidence/artifacts/blind-catalog-convergence-20260921/claude-wf2-usage.json)
therefore comes from the exact discovery workflow directory. Native workflow
summary tokens and per-model cache/input/output categories are different counters;
do not combine them or infer savings. Missing terminal results remain incomplete.

Discovery prompts excluded local catalog reads, but inherited instructions named
some existing tools and the trading destination. A mechanical top-12-by-stars
screen then favored popular projects and omitted smaller tools. The judges
themselves identified missing code navigation, research runtimes and evaluation
roles. The refuters rejected or narrowed **44 of 100** tested claims. A surviving
claim is still bounded by its source, version and inspected comparison set.
No candidate was cloned, built or executed by this discovery workflow.

## Corrections supported by original sources

- **Claude Code licensing:** the mechanical screen treated an unrecognized GitHub
  license as missing terms. The [pinned LICENSE.md](https://github.com/anthropics/claude-code/blob/b486776a2eef0d3f39abaebaa3c03e378c7480b8/LICENSE.md)
  explicitly supplies commercial terms, which that screen's own rule permitted.
  Correct the exclusion; do not describe the proprietary client as open source.
- **Runtime coverage:** F-agents omitted DeerFlow, Deep Agents and OpenHands SDK.
  The [current OpenHands repository](https://github.com/OpenHands/OpenHands/blob/2f8539de2fafbde5226c7e41c0d0aa7bea2533fa/README.md)
  describes Agent Canvas hosting native/ACP agents. Historical CodeAct benchmark
  results do not qualify this hosting product. Native workers retain their useful
  task and ownership evidence; full research applications remain conditional.
- **Maintenance wording:** [AutoGen](https://github.com/microsoft/autogen/blob/027ecf0a379bcc1d09956d46d12d44a3ad9cee14/README.md)
  directs new work toward Microsoft Agent Framework while retaining maintenance.
  That supports a new-project preference, not a claim the existing tool cannot work.
- **Nautilus IB scope:** [issue #4983](https://github.com/nautechsystems/nautilus_trader/issues/4983)
  reports Rust adapter v1.227.0 venue routing and explicitly distinguishes the
  Python adapter. It does not establish failure of our Python destination or
  installed 2.0.0rc5. Preserve the reported issue as a Rust-path qualification case.
  The [Alpaca RFC](https://github.com/nautechsystems/nautilus_trader/issues/3374)
  is not a released native adapter; the separate deterministic Alpaca path remains.
- **Memory benchmark scope:** [Mem0's README](https://github.com/mem0ai/mem0)
  explicitly attributes its current headline results to the managed platform,
  including proprietary optimizations absent from the open-source SDK. The
  [independent LoCoMo study, revision 5](https://arxiv.org/abs/2601.07978v5)
  compares Mem0, Graphiti, Cognee, RAG and full context; it does not test ai-memory,
  Basic Memory or Hindsight. These findings cannot select our memory store.
- **Time and provenance:** a dataset version, temporal graph or archived response
  preserves particular recorded states. It does not by itself establish when a
  vendor published information or whether a strategy could know it at the time.
  Playwright traces support debugging; deterministic archival replay needs its
  own capture, completeness and replay checks.
