# Independent report convergence

Read the [handbook](../../docs/grand-catalog-handbook.md) for the adopted direction
and the [final adjudication](../../docs/claude-blind-adjudication-20260921.md) for
the peer's original findings, later screening repair and independent corrections.
The dated source-review wave is complete; runtime quality and destination-PC
acceptance remain separate requirements.

`audit_reports.py --check` reproduces the complete original/later screening
ledger and joins every recommendation to the current canonical identity index.
It checks documentary accounting, not upstream source truth or quality. CI runs
the same check. Original peer reports remain unchanged; their scores and claims
are attributed, including disproved statements.

The source convergence experiment and the separate memory lifecycle experiment
retain their own scopes. The latter uses a tiny synthetic lexical corpus and
does not establish semantic recall superiority.

At final local verification, the catalog had 843 identities, 68 versioned
components, 20 layers and 134 receipts. Shared skill hashes and SDK locks are
separate linked records. No selected component or installed pin was changed by
the blind discovery wave; Grype's historical domain card was narrowed from a
default to a conditional, unexecuted scanner.

Verification: the Python suite reported 780 tests with two environment-dependent
skips; structure, evidence, landscape and all 17 convergence records passed after
correcting a documentation-schema mistake. The first final validation rejected
free-text notes in `failures_and_skips`; those cross-workflow caveats belong in
`limitations`, while this experiment's observations describe passed offline
checks. No validator was weakened. Earlier native failures and incomplete
attempts remain in their original artifacts.

The native browser exercised the offline explorer at mobile width: 843 visible,
no horizontal overflow, no external resource requests and no browser errors.
The repository-search and candidate-detail interaction were also exercised.
These checks cover this artifact and host; another WSL PC must repeat its own
installation, sign-in, useful task, memory and recovery acceptance.
