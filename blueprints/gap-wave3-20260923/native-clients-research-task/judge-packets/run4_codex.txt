Anthropic’s **prompt caching** lets production coding agents reuse previously processed prompt prefixes, such as tool definitions and repository context. It reduces repeated input-token processing, although it does not reduce the logical context length. Anthropic documents cache reads at **10% of the standard input-token price**, a 90% input-cost reduction for the cached portion ([documentation](https://docs.anthropic.com/en/docs/build-with-claude/prompt-caching)).
