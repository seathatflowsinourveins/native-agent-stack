Anthropic’s **prompt caching**, used by Claude Code, reuses previously processed prompt prefixes across calls. This reduces repeated input processing and token charges during coding sessions, although it does not reduce the context’s token count. Anthropic prices cache reads at **10% of the standard input-token price**, a 90% reduction for the cached portion ([official documentation](https://docs.anthropic.com/en/docs/build-with-claude/prompt-caching)).
