**Technique: prompt caching.** Anthropic offers it in the Claude API, and Claude Code uses it so each turn of a long agent session reuses the same starting prompt (system prompt, tool definitions and earlier conversation). The API stores that unchanged starting prompt, marked with `cache_control` breakpoints. Later requests that begin with the identical text read it from the cache instead of processing it again, so only the new tool results and messages cost full price. By Anthropic's published pricing, a cache read costs 10% of the base input-token price, which is a 90% saving on the reused part. The tradeoff is that writing to the 5-minute cache costs 1.25× the base price (2× for the 1-hour cache), so it only pays off when the start of the prompt stays the same and is reused before the cache expires.

These figures come from my knowledge of Anthropic's documentation; I didn't check the live pricing page in this session because you allowed only the one command.
