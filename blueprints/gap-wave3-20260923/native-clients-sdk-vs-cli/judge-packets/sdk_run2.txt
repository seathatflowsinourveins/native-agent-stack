**Technique:** Anthropic's prompt caching for the Claude API. Claude Code uses it to reuse the large, repeated prefix of each request: the system prompt, tool definitions and earlier conversation turns. **How it reduces tokens:** you mark a stable prefix as cacheable, and later requests that start with the exact same prefix read it from the cache instead of processing it again. Only the new suffix, such as the latest tool result or user message, is billed at the full input rate. **Benefit:** Anthropic's documentation prices cache reads at about 10% of the base input-token price, roughly a 90% saving on the cached part. It announced up to about 85% lower latency for long prompts. **Tradeoff:** writing to the default 5-minute cache costs about 1.25× the base input price, and changing anything early in the prefix (for example, editing tool definitions mid-session) invalidates the cache.
