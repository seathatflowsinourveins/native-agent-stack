**Technique:** Anthropic's prompt caching for the Claude API. Claude Code uses it to reuse the large, repeated prefix of each request: the system prompt, tool definitions and earlier conversation turns. **How it reduces tokens:** you mark a stable prefix as cacheable, and later requests that start with the exact same prefix read it from the cache instead of processing it again.
