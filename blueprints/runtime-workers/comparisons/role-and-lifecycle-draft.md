Harbor's [CooperBench adapter](https://github.com/harbor-framework/harbor/blob/1e5c5c6db929a10a140d05e606882c671ae20729/adapters/cooperbench/README.md) is a source-backed cooperative coding option, with two sidecars. Its ordinary Codex agent slot does not establish two-worker parity. Native SDK integration and image/dataset/route identity must be qualified first. Read the pinned verifier rather than treating process exit as the reward: it allows a union-merge fallback and can exit0 while recording reward0. This method remains a lead pending that original-source binding.

For each final preregistration, retain exact task/source/config/extension hashes, role effort mappings, retry0 or a declared recovery condition, attempt/time/token/tool limits, repeat order, native cache boundaries, original errors and unknown usage. Require the same useful-task oracle across arms, then apply a predeclared replacement rule. A fixture acceptance, version check or source-suite result cannot substitute for a job comparison. Claude reads before freeze and both families read the final head before adoption.

Promptfoo's stock review assertion computes `0.7*recall + 0.3*precision`, with recall>=0.75 and precision>=0.5. These explicit pass fields govern its object result; a declared numeric threshold is a separate native assertion path. A relative-winner assertion may intentionally fail a weaker arm; distinguish that result from infrastructure failure. This stock JSON issue-ID contract is not directly compatible with native Codex ReviewOutputEvent, PR-Agent Markdown or OpenHands' native review format. Use a separately frozen supported common rubric or resolve a maintained capture/normalization source before claiming parity. Preserve native turn missingness, provider usage and evaluator estimates independently. Price-table cost is not returned billing.
