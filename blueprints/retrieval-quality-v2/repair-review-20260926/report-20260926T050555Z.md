## Exact commands

Every qmd call runs with the scratch HOME as its working directory and a minimal environment: `PATH` and proxy/CA variables from the caller, `HOME`/`XDG_*`/`TMPDIR` under `$SCRATCH_HOME`, `INDEX_PATH=$SCRATCH_HOME/.cache/qmd/<index>.sqlite`, `QMD_CONFIG_DIR=$SCRATCH_HOME/.config/qmd`, `QMD_FORCE_CPU=1`, `NODE_LLAMA_CPP_GPU=false`, `NO_COLOR=1` and `MCP_AUTO_OPEN_ENABLED=false`. No other caller variable reaches qmd.

```sh
python3 blueprints/retrieval-quality-v2/run.py \
  --repo "$STACK_REPO" --scratch-home "$SCRATCH_HOME"

# what run.py runs under the hood:
qmd --index rqv2-sigterm-pull-check --version
qmd --index rqv2-sigterm-pull-check collection add "$STAGE/blueprints/us-equities" \
  --name rqv2-foundation --mask '**/*.md'
qmd --index rqv2-sigterm-pull-check collection add "$STAGE/catalogs/us-equities" \
  --name rqv2-catalog --mask '**/*.md'
qmd --index rqv2-sigterm-pull-check collection add "$STAGE/observability" \
  --name rqv2-observability --mask '**/*.md'
qmd --index rqv2-sigterm-pull-check update
qmd --index rqv2-sigterm-pull-check status
qmd --index rqv2-sigterm-pull-check search "<query>" -n 10 --format json   # Arm A
qmd --index rqv2-sigterm-pull-check pull    # Arm B only: default embed/generate/rerank models
qmd --index rqv2-sigterm-pull-check embed   # Arm B only
qmd --index rqv2-sigterm-pull-check query "<query>" -n 10 --format json    # Arm B
qmd --index rqv2-sigterm-pull-check bench "$SCRATCH_HOME/bench/fixture.json" --json   # upstream benchmark
```
