## Frozen scope and arms

Use the twelve public Gate A cases in tasks.json in both native client families, with three fresh-session repetitions per case. F-memory uses only the five catalog/history cases. Cases, source revision, seed, prompts, scoring, repetition count and analysis rules are fixed here before execution. Do not substitute a failed, uninvoked or unavailable case after seeing results.

F-token holds durable memory fixed and compares T-full, T-lean, an independently reset T-full-AA control, and T-full-minus-X for each entry of token_components in inputs.json. Each removal disables that component's CLI/MCP/plugin entry, hooks and emitted guidance in the trial-local configuration; unrelated components remain identical. T-full-minus-token-lane-carriers removes the shared SessionStart/SubagentStart token carrier only, preserving the component hooks. T-full-minus-context-mode and T-full-minus-rtk separately preserve the narrower historical contrasts. Read-only meters and the provider route remain fixed; meters are not claimed as savings tools.

F-memory holds T-full fixed and compares M-full, M-lean and an independently reset M-full-AA. Its one durable-memory component is the install plan's **interim ai-memory 2.5.2**, including its MCP exposure, capture hooks and emitted startup/handoff context. M-full-minus-ai-memory is exactly M-lean, not an extra independent condition. Codebase-memory-mcp is a token code graph. QMD is kept fixed in this memory contrast. This does not select ai-memory over the pending memory head-to-head.

Freeze the actual component-to-interface map and arm-local JSON/TOML at the release gate. Do not alter shared client settings, templates, accounts, routes or memory stores. A missing component is unavailable, not silently enabled or scored as a zero-effect treatment. Changing the component map, pin, dataset or actual model requires a new preregistration and ACK, not an unrecorded repair.

## Equal quality and controls

The amended task prompts and output-only oracles in tasks.json apply equally to every arm. Catalog/history answers can use direct frozen sources; a mandatory memory/MCP hit would mechanically penalize M-lean. Original adoption predicates and tool-hit counts remain separate diagnostics. The amendment is explicit; these are local task/oracle definitions, not upstream benchmark tests.

Grade against the exact base revision and original fixtures, independently of the agent's answer and chosen tool. Every required fact, event number, sum, AST definition and direct Name-call location must match. An omitted result, wrong source, fabricated citation or changed input fails. Preserve all unsuccessful attempts. A component invocation is neither factual correctness nor a token saving.

Before full trials, the ACKed pilot must prove: two distinct child lineages joined by the parent; unchanged frozen inputs; matched model/effort and tool exposure; complete provider usage for parent, all children and auxiliary model calls; and a checker that rejects deliberately wrong or empty answers. ## Accounting boundary and reserved future confirmatory design

The reserved future confirmatory efficiency metric, per client family and contrast, is **all complete provider tokens across every attempt divided by accepted tasks**. It is not the operational decision criterion for this exploratory pack. Include preparation, memory/index initialization, parent, children, model-powered compression/retrieval, grading/review, failed attempts and native retries. Account for preparation per independently reset trial rather than hiding it as free shared warmup. Keep deterministic no-model work, wall time and list-price cost separate. A zero-success arm has no finite accepted-task ratio.

Normalize disjoint uncached input, cache creation, cache read and inclusive output. Codex cached input is a subset of input; derive uncached input only when both are known. Reasoning is an output subset. Claude prompt totals include ordinary input, cache creation and cache reads. Select one authoritative provider counter per unique invocation; do not add cumulative snapshots, native result totals, model totals, ATIF totals or child totals to their constituent calls again. Deduplicate native IDs and retain a coverage inventory that accounts for every role and attempt. Unknown categories, retries or cost remain null.

Harbor's Claude importer reads parent and child JSONL and deduplicates event UUIDs, but missing fields can become zero in its metrics. Verify native presence before accepting those zeros. Its Codex importer selects one rollout; the Harbor aggregate alone is insufficient evidence of complete Codex multi-agent usage. Retain and independently reconcile all parent/child native rollouts with provider totals. If the supported upstream interfaces cannot do this, record the family as blocked/inconclusive and propose the gap to the owner; do not build a replacement runner or claim savings from partial totals.

Report raw tool-output tokens entering context, exact original recovery, task success, wall time, retries and cost separately. Raw output uses the frozen tokenizer/configuration in the release pack and is an artifact metric, not provider usage. Preserve native cache behavior; block and counterbalance order by case, repetition and family. Repeat A/A controls through independent fresh sessions; never replay the same result as a new observation.

A/A has a predeclared validity gate: for each family and layer, its primary-ratio task-cluster interval must contain one and its conservative quality-difference interval must contain zero. Use alpha=0.025 for the two layer controls within each family. An undefined interval, missing coverage, failed lineage/input/profile check or an interval excluding its null blocks confirmatory interpretation for that family/layer. An interval containing the null is necessary only; it does not establish equivalence or absence of order/cache bias. Report A/A outcomes even when blocked. The deliberately wrong-answer, missing-child and wrong/empty-memory controls must also discriminate as specified.

Unique execution inventory is 18 token arms (full, lean, full-AA and fifteen removals) times twelve cases times two families times three repetitions, plus three memory arms times five cases times two families times three repetitions: **1,386 parent trials**, with at least **2,772 child lineages**, before auxiliary work. Shared baseline observations may be referenced by multiple contrast records but are one invocation in the execution/provider inventory; never sum those record totals into a batch total. No part of this inventory has run.

For each family, publish all per-case/repetition outcomes before aggregate conclusions. The common-success paired geometric token ratio is secondary and cannot replace the failure-inclusive primary metric. Token-ratio intervals use SciPy 1.18.1 (e4e854eaa8f18d807cd3496028e257e36caa93cc) bootstrap with paired=True, method=percentile, 10,000 resamples and NumPy 2.5.3 (dd88c0c19b54ad9ed3533224221285bf0873249a) RNG seed 20261006. Resample task clusters with the same indices across arms, preserving all three repetitions within each cluster. Compute the statistic as the ratio of the two failure-inclusive totals-per-accepted-task, not the mean of task ratios. Do not drop zero-success resamples; any undefined resample makes that interval inconclusive. Never treat repetitions or children as independent task samples.

The following confirmatory recommendation/removal rules are **inactive** until a separately frozen amendment is ACKed. A confirmatory saving recommendation would require complete usage, passing controls, a conservative lower bound for candidate-minus-baseline task success above -0.10, and the upper simultaneous 95% interval of the primary candidate/baseline ratio below 0.95. Per client and layer, K is the fixed number of non-control contrasts; use Bonferroni alpha=0.05/K, including uninvoked/unavailable contrasts in K. Token intervals use confidence_level=1-alpha. Quality is task-cluster binary acceptance only when all three repetitions pass. For the candidate-only and baseline-only accepted cluster proportions, use SciPy binomtest(...).proportion_ci(method=exact, confidence_level=1-alpha/2). The difference bounds are [L(candidate-only)-U(baseline-only), U(candidate-only)-L(baseline-only)], covering both discordant proportions without a degenerate all-success bootstrap. No pooled cross-client win. A confirmatory component-removal suggestion would require quality equivalence within +/-0.10 and raw-output/provider-ratio equivalence within [0.95,1.05]; an interval merely crossing one is inconclusive. These margins are design references, not the current operational gate or historical measured findings. No installation or removal follows automatically.

The five memory cases and twelve total cases remain a bounded exploratory corpus. Under the reserved conservative exact method, the best-case minimum per client is **68 independent token cases at K=16** and **42 independent memory cases at K=1**. With zero discordance in both directions, the quality bounds are [-U,U], where U=1-(alpha/4)^(1/n) and alpha=0.05/K. Token n=67 gives U=0.1012814; n=68 gives U=0.0998690. Memory n=41 gives U=0.1013653; n=42 gives U=0.0990756. These are strict +/-0.10 reachability floors, not a power guarantee or measured result; repetitions and children are not additional independent cases. The current corpus cannot qualify those margins. Keep the matrix withheld and do not enlarge this corpus.

**Overturn condition:** a live layer shows a quality regression, or the user requests confirmatory savings. Either trigger leads to a separately frozen confirmatory amendment with its corpus, power and decision rules reviewed before any run. It does not start the matrix automatically. Without a trigger and exact-head ACK, preserve the current defaults and observational practice.

Use ai-memory's supported isolated data-dir/config/server-url paths. SessionStart inbox reads can consume state: use an independently reset store and inbox per arm, never the production store. Harbor memory_dir is not an MCP-store clone; its seed copy can suppress errors. Stage only the public seed and verify its delivered hashes. No private history or authentication file is copied.

The planned convergence records have no observations, failures, qualification IDs or usage claim. Each record names exactly one baseline/candidate contrast.
